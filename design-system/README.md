# Meal Planner Design System

Локальный router-agnostic пакет интерфейсных токенов и компонентов Meal Planner. Пакет используется основным Next-приложением и отдельной Vite-админкой, но не содержит бизнес-логики, API-клиентов, guards или маршрутов.

## Темы

- `coffee-light` — тема клиентского приложения по умолчанию;
- `coffee-dark`;
- `nature-light`;
- `nature-dark` — тема административного приложения по умолчанию.

Приложение владеет сохранением настройки и передаёт выбранное значение в контролируемый `ThemeSwitcher`. В DOM тема задаётся через `data-theme` на `html`.

## Границы

- `foundations` — типы и функции тем;
- `styles` — reset, семантические tokens и базовые поверхности;
- `components` — доступные React-примитивы без зависимости от Next или React Router;
- `AppShell` принимает навигацию и renderer ссылок через props, поэтому не знает URL продукта и конкретный роутер;
- `PublicShell` задаёт общий header/footer публичных страниц, отделяет обычную навигацию от CTA по `tone`, но получает пункты, renderer ссылок, бренд и theme control от приложения; theme control находится в footer и остаётся доступен на desktop/mobile без перегрузки header;
- `AuthShell` задаёт двухколоночную auth/service-композицию с передаваемыми брендом, иллюстрацией и формой, не владея сессией или сценарием входа;
- `ServiceShell` задаёт отдельную desktop/mobile-композицию служебного приложения и принимает его навигационные группы и renderer ссылок через props;
- `AppIcon` содержит канонический набор интерфейсных glyph для общей навигации.

Все shell-компоненты отвечают только за композицию, адаптивность и доступную разметку. Next/React Router, guards, URL, бизнес-состояние, запросы и хранение выбранной темы остаются в приложениях-потребителях.

Цвета контента должны использовать семантические токены темы: основной текст — `--ink`, вторичный — `--muted`, ссылки и CTA — `--accent`. Резко выделяющийся произвольный цвет не переносится из reference-макета без функциональной семантики (например, danger/success/status).

Системный scrollbar также является частью темы: общий base-слой задаёт ширину 8 px, скрывает browser arrows и использует `--mp-color-scrollbar-*` для track/thumb/hover во всех scroll-контейнерах приложений.

Пакет входит в npm workspace `meal_admin` и подключается приложениями через `file:./design-system` из корня. Установка всех пакетов — `npm ci` в корне репозитория; отдельная установка в этой папке не нужна. React и его типы должны разрешаться из общей установки workspace.
